LLM Games Lab

How this works

  1. The model gets one of the three prompts below, pasted in word for word. No follow-up nudge when it goes wrong.
  2. Whatever comes back is what gets tested. A broken file stays broken.
  3. I play it in Chrome, long enough to have an opinion worth writing down.
  4. Then I write down that opinion.

There is no score out of ten. I tried scoring the first few and every number I picked said less than a sentence would have, so the write-ups end in a paragraph instead. The model, the reasoning effort and the harness it ran through are listed on each result page.
